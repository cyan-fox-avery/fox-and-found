# Fox & Found — Opening Loop Prototype v2

This folder contains a deliberately small vertical slice for testing the opening feel of Fox & Found.

It is **not** the final game architecture or final visual design.

## What v2 tests

- Welcome screen before Week 1
- Five-tab rescue interface:
  - Overview
  - Foxes
  - Intake
  - Facilities
  - Records
- Persistent week, funds, standing, and intake status
- Loki as the permanent tutorial resident
- Correct portrait-style framing for Loki's photo
- Startup funding and required dig-proof reinforcement
- Opening the rescue for intake
- FOX-002's intake call and assessment
- Naming the first rehabilitation fox
- Milestone-based weekly rehabilitation
- Camera observation and positive human avoidance
- Voluntary transfer of an already accepted fox
- No Professional Standing penalty for a responsible voluntary transfer
- Records for referred, transferred, or released cases
- Mobile-friendly tabbed layout

## Not included yet

- Full economy balancing
- Supply consumption
- Randomized case pools
- FOX-003 through FOX-005 as playable cases
- Full partner-update chains
- The post-tutorial upgrade choice
- Full case archive
- Real FOX-002 photography
- Final visual design

The prototype uses the existing real Loki photo from `images/foxes/fox-001-loki.jpg`. FOX-002 intentionally has no image yet rather than using a generated placeholder.

v2 uses a new local-storage key, so an old v1 prototype save will not interfere with testing.
