# Fox & Found — Opening Loop Prototype

This folder contains a deliberately small vertical slice for testing the opening feel of Fox & Found.

It is **not** the final game architecture or UI.

## What it tests

- Week-based presentation
- Loki as the permanent tutorial resident
- Startup funding and required dig-proof reinforcement
- Opening the rescue for intake
- FOX-002's intake call and assessment
- Naming the first rehabilitation fox
- A short milestone-based rehabilitation loop
- Camera observation and positive human avoidance
- Release
- Mobile-friendly layout

## Not included yet

- Full economy balancing
- Supply consumption
- Randomized case pools
- FOX-003 through FOX-005
- Referrals and partner updates
- The post-tutorial upgrade choice
- Full case archive
- Real FOX-002 photography
- Final visual design

The prototype uses the existing real Loki photo from `images/foxes/fox-001-loki.jpg`. FOX-002 intentionally has no image yet rather than using a generated placeholder.
