# Fox & Found

**Fox & Found** is a small, finite fox-rescue management and upgrade game.

The player runs a growing fox rescue, takes in authored individual cases, provides appropriate care and rehabilitation, decides when the sanctuary has capacity for new intakes, and works toward the best welfare outcome for every fox.

## Core principles

- Welfare comes before collection or score.
- A successful release is a major success.
- Permanent sanctuary placement can also be a successful outcome.
- Responsible referral to a partner facility is a good decision when Fox & Found is not the right place for a case.
- Foxes are individual authored characters, not procedurally generated animals.
- The campaign has a real ending, with optional post-win play.
- There is no prestige-reset treadmill.
- Failure affects the organization, not the animals.
- Foxes are wild animals, not collectible pets.
- Real wildlife photography is preferred for visual assets.
- No generative AI imagery is used for Harley's game.

## Current status

Early design and prototyping.

The current design roster includes:
- **FOX-001 — Loki:** permanent sanctuary resident / tutorial fox
- **FOX-002:** first rehabilitation and release case
- **FOX-003:** demodectic mange / diagnosis-before-assumption case
- **FOX-004:** sarcoptic mange / first referral case
- **FOX-005:** entanglement / capacity-planning case

A small playable vertical slice lives in `prototype/`. It is intentionally narrow and exists to test the opening loop before the full game is built.

## Visual assets

Fox & Found uses properly licensed real wildlife photography. Photographs represent fictional rescue cases and should not be interpreted as describing the real photographed animals.
