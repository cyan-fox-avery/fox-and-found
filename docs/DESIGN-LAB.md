# Fox & Found — Design Lab

This branch is a shared sketchbook for Fox & Found design experiments.

## How it works

- Experimental files live on this branch: drafts, half-formed case ideas,
  prototype spikes, notes, what-if scenarios.
- The pull request for this branch is the shared design thread. Discussion
  happens there, not scattered across chats.
- **This branch is never merged into `main`.** Finished work graduates to
  `main` through its own focused pull request.
- `main` stays clean and playable at all times.

## Who's here

- **Avery** — creative direction, final say on everything.
- **Muse** — can commit experimental files to this branch on request.
- **ChatGPT** — Avery's main build collaborator. Designs and drafts can be
  shared in the PR conversation (pasted in by Avery) or committed here as
  files for review.

## Ground rules

- Label speculative ideas as speculative. Canon lives in `docs/` on `main`.
- Welfare-first, always: every experiment must respect the design principles
  in `docs/DESIGN.md`.
- Nothing here is a promise. The lab is for trying things.
- When an experiment is done and Avery approves it, it moves to `main` via
  its own PR — never by merging this branch.
