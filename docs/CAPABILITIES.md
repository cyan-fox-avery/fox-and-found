# Fox & Found — Capabilities & Early Upgrades

## Purpose

Capabilities describe what Fox & Found can safely and responsibly do. They are not generic stat boosts.

A case may require one or more capabilities. Upgrades expand those capabilities or increase practical capacity.

## Early capability matrix

| Capability | Start | Unlock | Effect |
| --- | :---: | --- | --- |
| Basic intake | Yes | Starting facility | Intake and assess uncomplicated cases |
| Basic quarantine | Yes | Starting facility | Short-term separation for new cases |
| Basic rehabilitation | Yes* | Tutorial reinforcement | One uncomplicated rehabilitation case |
| Low-contact care | Yes | Starting facility | Release-oriented care with minimal human interaction |
| Camera observation | Yes | Starting equipment | Observe behaviour without unnecessary disturbance |
| Second rehab slot | No | Second Rehabilitation Enclosure | Adds another general rehabilitation space |
| Infectious-disease isolation | No | Infectious-Disease Isolation | Allows safe care of contagious cases |
| Expanded food reserve | No | Improved Food Storage | Supports a larger caseload with a safer supply buffer |
| Formal grant administration | No | Improved Office & Records | Unlocks grant opportunities and later admin progression |
| Kit care | No | Later specialist upgrade | Allows dependent/orphaned juvenile cases |
| Advanced medical recovery | No | Later medical-space upgrade | Supports more complex injuries and recovery |
| Long-term sanctuary housing | No | Later permanent-care enclosure | Allows additional non-releasable residents |
| Advanced transport | No | Later transport upgrade | Supports more difficult rescues/transfers |
| Intensive monitoring | No | Later equipment upgrade | Supports medically or behaviourally sensitive cases |

*The physical rehab run exists at the start but is not fox-ready until the tutorial dig-proof reinforcement is installed.

## First upgrade set

### Improved Food Storage
Prototype cost: **$450**

Adds better refrigeration/freezer capacity and food-preparation storage.

### Improved Office & Records
Prototype cost: **$600**

Unlocks formal grant opportunities, better partner/case records, and later accreditation progression without turning paperwork into a repetitive minigame.

### Second Rehabilitation Enclosure
Prototype cost: **$900**

Adds one general rehabilitation slot and makes overlapping cases easier to manage.

### Infectious-Disease Isolation
Prototype cost: **$1,100**

Adds separated infectious-disease housing and dedicated disease-control equipment. It unlocks safe intake of contagious cases such as sarcoptic mange.

## Design rule

An upgrade should answer:

> **What can Fox & Found safely do after buying this that it could not safely do before?**

If the answer is only “+10% efficiency,” reconsider the upgrade.
