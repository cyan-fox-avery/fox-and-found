# Fox & Found — Fox Roster

## FOX-001 — Loki

- **Status:** Locked as the tutorial fox and permanent first resident of Fox & Found
- **Species:** Red fox (*Vulpes vulpes*)
- **Name:** Loki
- **Naming:** Already named by Harley; the player does not rename this tutorial resident
- **Role:** Tutorial / permanent sanctuary resident
- **Release status:** Non-releasable
- **Reason for permanent care:** Human habituation *(provisional detail; can still be revised)*
- **Personality direction:** Clever, mischievous, chaotic *(provisional beyond the core “Loki” concept)*
- **Image:** `images/foxes/fox-001-loki.jpg`
- **Photo source:** Wikimedia Commons, Kumweni, CC BY 2.0

### Design purpose

Loki introduces the player to basic sanctuary care and establishes early that permanent sanctuary placement can be a successful welfare outcome rather than a failure to release.
